# SendMock Homebrew tap

Homebrew formulae for [SendMock](https://github.com/shibbirweb/sendmock), the local email, SMS, push, payment and webhook catcher for development and CI.

## Install

Stable:

```bash
brew install shibbirweb/tap/sendmock
```

Beta:

```bash
brew install shibbirweb/tap/sendmock-beta
```

The formulae in `Formula/` are written by SendMock's release workflow for every release; do not edit them by hand. Report problems in the [SendMock repository](https://github.com/shibbirweb/sendmock/issues).
